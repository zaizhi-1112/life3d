# 二十三（演示版）

一座黄昏小岛，把这几年的经历和「今日小物」每天打印的摆件放在一起。支持本机工作台联动和独立的公网只读演示。

## 目录
- `serve.py`：本机服务，只绑 127.0.0.1。`/data/world.json` 和 `/models/<展品 id>`。
- `demo/`：已脱敏的世界快照和展品模型。人名、群名、学校、公司和账号 ID 均已替换。存在快照时服务直接展示它。
- `tools/build_world_data.py`：从私有的经历汇总和今日小物任务生成 `world.json`（设置 `BIRTHDAY_WORLD_DATA` 时启用）。
- `web/`：无构建的静态页面，`vendor/three/` 是本地 three.js r169（MIT）。
- `assets/`：代码生成的场景小物（GLB）。

## 运行
```
PORT=5232 WORKBENCH_PORT=17868 python3 -I serve.py
```
打开 http://127.0.0.1:5232/ 。「今日小物」按钮会嵌入同级目录的工作台（端口 17868）。

## 边界
- 往 Aholo 只发造型描述，不发人名、原话或聊天内容。
- 卡片编辑只写本机 `data/edits.json`。

## 布置与资产
- 顶部「资产管理」打开资产面板：每日小物（含已打印）、Aholo 精雕都能在岛上拖动、转向、缩放、收进仓库或放回原处。小屋随人物生成，不进面板。
- 摆放只写本机 `data/layout.json`（没有时用 `demo/layout.json` 的默认摆放）：`{"items": {<展品 id>: {"x","z","yaw","scale","hidden"}}}`。坐标为世界米数，`yaw` 为相对默认朝向的角度，`scale` 0.6–1.6。只存与默认摆放不同的件；删掉某件即放回系统位置。
- 服务端只接受当前 world.json 里登记的展品 id，坐标须在岛内。重建世界不改动 layout.json；展品被撤下时其摆放保留但不生效。

## 记忆宫殿（`/palace.html`）
- 同一批资产（每日小物的 Aholo 模型、已打印的实物、世界精雕）加上家具摆设，可以摆进小屋（18×13 米，墙只朝里，俯瞰像娃娃屋）或海上的花园（半径 20 米），也能回到小岛。场景和家具全部由代码生成（`palace-furniture.js`），不花 Aholo 积分。
- 「自动」按收藏量和时间推荐场景并写明理由：小物 ≤30 件进小屋，≤60 件进花园，更多建议回小岛。用户手选后记住选择。
- 「走进去」切第一人称：WASD 走、拖动看、Shift 跑，家具有碰撞；「俯瞰」或 Esc 回到第三人称。
- 平时只能看和点（点物件出卡片，点打印机开今日小物）；打开「资产管理」才进入布置模式，能拖动物件和家具、Q/E 转向、缩放、收起、撤销。家具上的物件跟着家具一起移动和转向；家具收进仓库时，上面的物件一起收起。可以从面板再添家具（新家具编号 `f-<类型>-<随机>`，带 `type`），新添的可删除，默认家具只能收起。
- 已打印的作品成对出现：数码模型 + 实物照片相框（有照片时）和「实物」铜牌。
- 首次进入由默认摆放算法排好（最新一件放茶几或凉亭，已打印的进实物陈列柜，其余按日期上展示墙和书架或沿花园小路的石台，精雕挑代表件上展台或花坛）；「重新帮我摆好」只重排当前场景，保留用户新添的家具，可撤销。
- 摆放只写本机 `data/palace.json`：`{"scene": "auto|room|garden", "rooms": {"room|garden": {"items": {<id>: {"x","y","z","yaw","scale","hidden","type"}}}}}`。服务端只收 world.json 里登记的展品 id 和 `f-` 开头的家具 id，`type` 必须是已知家具类型，坐标在场景范围内（|x|、|z| ≤ 24，0 ≤ y ≤ 4），scale 0.5–2。与岛上的 `layout.json` 互不影响。

## 海、声音、动效
- 岛周围和花园外的海由 `ocean.js` 生成：Gerstner 波在着色器里起伏，靠岸有白沫，船随浪起伏；`waveHeight` 与着色器同一套公式。
- 声音全部由 `sound.js` 用 WebAudio 合成（海浪、小屋钟摆、花园鸟叫、点按、拿起放下、开合卡片、脚步），第一次点按后才出声；右下角「声音」可静音，记在浏览器本地。
- 按钮按下回弹、卡片和面板滑入、物件出现时弹起、放下时回弹、场景切换淡入淡出。系统设置「减少动态效果」时动画关闭。

公网发布从仓库根目录运行 `node build-site.mjs`，服务目录为 `public/`。公网页面带 `data-read-only`：卡片只读，资产管理和今日小物入口隐藏，记忆宫殿可以浏览和第一人称逛，不能布置。本机启动方式见上。
